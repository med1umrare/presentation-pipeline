# Presentation QA Report

```yaml
artifactType: presentation-qa-report
schemaVersion: "1.2"
buildManifest: build-manifest.json
```

Используй статусы `pass`, `fail`, `warning`, `not-applicable`. Для каждой строки приложи доказательство: путь к рендеру, измерение, лог или краткое наблюдение.
